# Domain docs

This is a single-context repository.

## Before exploring

- Read the root `CONTEXT.md`.
- Read relevant ADRs under `docs/adr/`.
- Proceed silently if either location does not exist.

## Vocabulary

Use the canonical terms from `CONTEXT.md` in issues, specifications, plans, tests, and
implementation work. Avoid synonyms that the glossary rejects.

## ADR conflicts

If proposed work conflicts with an ADR, state the conflict instead of silently overriding the
decision.
